# Pushkar's Calculator 🧮

A simple yet complete Python calculator application that performs multiple mathematical operations.

## Description
This is a beginner-friendly calculator program built with Python. It allows users to perform basic to advanced mathematical operations in an interactive command-line interface.

## Features ✨
- ➕ **Addition** (+)
- ➖ **Subtraction** (-)
- ✖️ **Multiplication** (*)
- ➗ **Division** (/)
- 🔢 **Power/Exponentiation** (**)
- 📊 **Modulo** (%) - Remainder after division
- ⌊⌋ **Floor Division** (//) - Integer division

## How to Use 🚀

### Requirements
- Python 3.x installed on your system

### Running the Program

1. Save the code as `calculator.py`
2. Open your terminal/command prompt
3. Navigate to the folder where the file is saved
4. Run the following command:

```bash
python calculator.py
```

### Example Usage

```
***PUSHKAR'S NEW CALCULATOR***
ENTER THE FIRST NUMBER: 15
ENTER THE OPERATOR: +
ENTER THE SECOND NUMBER: 25
Answer:  40
DO YOU WANT TO RUN AGAIN? (yes/no) : yes

ENTER THE FIRST NUMBER: 100
ENTER THE OPERATOR: /
ENTER THE SECOND NUMBER: 4
Answer:  25.0
DO YOU WANT TO RUN AGAIN? (yes/no) : no

```

## How It Works

1. The program displays a welcome message with the calculator name
2. User enters the first number (integer)
3. User enters an operator (+, -, *, /, **, %, //)
4. User enters the second number (integer)
5. The calculator performs the operation and displays the result
6. User can choose to perform another calculation or exit

## Features Explained

| Operator | Operation | Example |
|----------|-----------|---------|
| + | Addition | 10 + 5 = 15 |
| - | Subtraction | 10 - 5 = 5 |
| * | Multiplication | 10 * 5 = 50 |
| / | Division | 10 / 5 = 2.0 |
| ** | Power | 2 ** 3 = 8 |
| % | Modulo | 10 % 3 = 1 |
| // | Floor Division | 10 // 3 = 3 |

## Code Logic

- Uses a **while loop** to allow multiple calculations
- Checks user input with **if-elif statements**
- Converts input strings to **integers** for calculation
- Handles invalid operators with error messages
- Asks user if they want to continue after each calculation
